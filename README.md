<table>

<td width="60%" valign="top">

**[Natorous](https://natorous.netlify.app)** — expedition travel landing page
A dark-editorial, fully-responsive site built with **Vite + Sass (7-1) + BEM** and **zero runtime dependencies**. Every section renders from one editable `site.config.json` — a company can rebrand by editing a single data file and redeploying.

**Highlights:** framework-free component system · ≈6 kB gzipped JS/CSS · self-hosted variable fonts · scroll-spy & reveal animations · accessibility (skip-link, ARIA, reduced-motion) · live on Netlify with GitHub auto-deploy
